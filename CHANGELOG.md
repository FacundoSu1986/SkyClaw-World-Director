# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
this project intends to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
once it produces a released artifact. Until then, there are no version numbers — only
dated entries, because nothing is shipped yet.

## [Unreleased]

### Added

- Initial concept documentation: `README.md`, `docs/ARCHITECTURE.md` and
  `docs/ROADMAP.md`.
- Architecture Decision Record structure under `docs/adr/`, with the open decisions
  (IPC transport, persistence mechanism, actor classification, license) listed as
  explicitly undecided.
- Repository conventions: contributing guide, security policy, code of conduct, issue
  and pull request templates.
- Documentation CI: markdown linting and offline link checking.
